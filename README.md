## 👋 About Me

I build data pipelines and data solutions that transform raw data into reliable, analytics-ready datasets.

My experience combines production SQL database development with hands-on data engineering projects across cloud platforms, data integration, transformation, data quality, and business intelligence. I have built projects using Azure Data Factory, Azure Data Lake Storage, Databricks, Microsoft Fabric, dbt, Prefect, Snowflake, and AWS S3, applying modern data engineering practices to practical business scenarios.

I am particularly interested in building scalable data solutions that support better reporting, data quality, and business decision-making, especially within financial services and banking.
